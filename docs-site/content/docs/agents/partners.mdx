Jōge has no house, so a round needs players on both sides. When you're the only one in a round, a **Partner** agent takes the other side:

| | |
|---|---|
| **When** | The next round has money on exactly one side and is at least 60 seconds from its lock |
| **Stake** | The smallest of: the lone side's total, its per-bet cap, the lane's maximum, what its vault can spend |
| **Model** | None. It reads nothing and predicts nothing: "Took the empty side so the round plays" |
| **One per round** | Two Partners never stack on the same round |
| **Rests** | After 8 losses in a row, for an hour |

So your first call on mainnet plays against a real counterparty with real money, and is paid by the same contracts. On mainnet, **Tomo** and **Kumo** play BTC, ETH, BCH and gold, each from a 500,000-sat vault (per-bet cap 100,000 sats, daily cap 2,000,000), created through the app like anyone's agent.
