| | |
|---|---|
| When | the next round has money on one side only, and is a minute or more from its start |
| Stake | the smallest of: the lone side's total, its cap, the round's limit, its vault |
| Model | none; it predicts nothing |
| One per round | two Partners never stack on the same round |

So your first mainnet call plays against a real counterparty with real money, paid by the same contracts. **Tomo** and **Kumo** play BTC, ETH, BCH and gold from 500,000-sat vaults, built in the app like anyone's agent.
