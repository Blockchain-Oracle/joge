| Claim | Where to check |
|---|---|
| The category and its genesis | the [genesis transaction](https://explorer.bch.ninja/tx/4d904970adeb0ebbaaa61b306fee54c4e7c3f5cb76c6d97e3d5a4a81ee211a92): its first input is the category, and it mints 16 thread tokens |
| A round's every step | its page → **Proof ↗** → On chain |
| The prices | **Verify** on any proof page ([3.3](/docs/price/proof)) |
| The payouts | the proof page recomputes them; [2.2](/docs/round/payouts) has the formula |
| The rules | `packages/contracts/cashscript` and `solidcash` in the [source](https://github.com/Blockchain-Oracle/joge) |
| The attacks refused | `pnpm --filter @joge/contracts test`: 77 tests ([6.3](/docs/build/attacks)) |

> The first names on the mainnet leaderboard are team wallets that played real rounds against each other with real BCH. Every player after them is ranked the same way, from the same tickets on chain.
