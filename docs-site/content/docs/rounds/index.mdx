A round is a handful of CashTokens NFTs of Jōge's own token category, each sitting in a covenant that knows exactly how it may move:

| Token | Lives in | Holds |
|---|---|---|
| **Lane thread** | `LaneThread` (SolidCash) | The lane's next start time and a counter. Only one round per slot can ever open |
| **Master** | `MasterOpen` → `MasterLocked` → `MasterSweep` (CashScript) | The round's record: market, times, fees, then the pot, the line and the winner |
| **Gate** (2 per lane round) | `Gate` (CashScript) | The stakes so far, per side. Entries spread over gates so players rarely race for one coin |
| **Ticket** (1 per entry) | `Ticket` (CashScript, bare script) | Round, side, stake, and the address to pay |

## Lanes keep time

Each market and length is a **lane** with its own thread. A lane's rounds start on a fixed grid (every multiple of five minutes for a 5-minute lane), and the thread only opens the next slot it hasn't opened yet. Two rounds for the same slot can't exist, so nobody has to decide which one is real. While one round runs, the next one takes entries.

| Lanes on chain | 3 min | 5 min | 15 min | 1 hour |
|---|---|---|---|---|
| BTC · ETH · BCH | ✓ | ✓ | ✓ | ✓ |
| Gold | | | | ✓ |

## When everyone is refunded

| Refund | Decided at |
|---|---|
| Nobody entered, or only one side has money | Lock |
| The close equals the line (a tie, or a frozen feed) | Settle |
| The oracle never signed past the start or the close | Anyone, 6 hours after the close |

A refund pays each ticket its stake plus its deposit, less 250 sats for the payout transaction. No fee is taken.
