title: Attacks the contracts refuse
description: 77 contract tests, 23 of them attacks. Each one tries to steal, inflate or reorder something, and each is refused by the contract with its own rule.
icon: Swords
---

The contract tests run every function against Bitcoin Cash's own script VM with real General Protocols messages as fixtures. `pnpm --filter @joge/contracts test`: **77 tests, all passing**.

| Attack | Refused because |
|---|---|
| Stake below 5,000 sats or above the lane's cap | "stake outside this round's bounds" |
| An outcome the round doesn't have | "no such outcome" |
| Inflate the gate's totals | "gate totals must add this stake" |
| A ticket that claims more stake than was paid | "ticket must record round, gate, outcome, stake and payee" |
| Send the ticket anywhere but the ticket contract | "output 1 must be the ticket" |
| Mint an extra ticket from the gate | "at most gate, ticket and change" |
| Smuggle another player's ticket in as funding | "funding inputs carry no tokens" |
| Overfill a gate | "gate is full" |
| Lock with a gate left out | "every gate, and nothing else, must be merged" |
| Lock with gates out of order | "gates must be in gate order" |
| Smuggle a ticket into the lock | the ticket "moves only with its settled master" |
| Lock before the oracle has signed past the start | "first message must be at or after the boundary" |
| Take more than the fixed lock fee | "fixed lock fee" |
| Send a second variant of the same lock | "fixed sequence" / "lock carries no locktime" |
| Use any line but the message after the lock | "strike must be the message after the lock message" |
| Name the other side as winner | "the settlement record must be exact" |
| Add an output or a ticket at settle | "no other outputs" / "settlement spends only the master" |
| Pay a ticket more than its share | "payout amount" |
| Pay anyone but the ticket's owner | "output pays the ticket's owner" |
| Burn the master while tickets are unpaid | "the master carries on, or goes back to its creator after the last ticket" |
| A payout that pays no ticket | "a sweep takes at least one ticket" |
| Pay a ticket from another round | "ticket belongs to another round" |
| A creator fee above 3% | "creator fee above the cap" |

## Also refused

| Contract | Refused |
|---|---|
| Lane thread | A slot already opened, a slot off the grid, a slot more than two lane lengths ahead of the signed clock, a round record with another fee |
| Factory | A fee over 3%, a round under 3 minutes, gold under an hour, falling price ranges, a close past the feed's end, a start more than 30 days ahead |
| Agent vault | A stake above the cap, a ticket for anyone but the owner, another key, a withdrawal by anyone but the owner |
| Event gate | An exit signed by anyone but the ticket's owner, a signature that doesn't cover every output, an exit from a lane round |
| Oracle checks | Non-consecutive messages, a pair before the boundary, another feed's key, a tampered price, a wrong-length message |
| Timeouts | A void before its deadline, or with a final sequence |

## What the design bounds instead

Two things no contract can rule out on a 10-minute-block chain, and how Jōge keeps them small:

| Risk | Bound |
|---|---|
| Late entries if nobody locks on time | Lock is free and identical for everyone: the keeper sends it within seconds, and any round page offers it |
| A loser double-spending an unconfirmed entry after the result | Small caps per entry and per gate on short lanes; entries are spread over gates so one reversal touches only part of a round |
